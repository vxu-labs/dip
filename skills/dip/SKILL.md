---
name: dip
description: Manage persistent task intent and handoffs in a project using DIP while automatic hooks record ordinary development activity.
---

Follow the project's selected DIP workflow. In automatic mode, trusted hooks capture prompts, actions, native plans and file changes; they coordinate ownership before supported writes. Do not make management calls for questions or read-only investigation. For development, use task_finish once at the end (implemented with remaining-work review and a configured check, or paused with remaining items). Native plans need no second copy. Explicit adoption, future ideas, meaningful scope changes and conflict resolution remain available. Stop never proves completion. If hooks are disabled or untrusted, persist intent explicitly. In reviewed mode, follow the existing prepare/finish workflow in AGENTS.md. Read task_get or task_requirements only when needed. Never call another model for tracking.
