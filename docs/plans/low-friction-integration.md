# Complete the bounded integration backlog

## Intent transitions (L04)

Add an explicit task adoption operation: the existing agent reviews a captured follow-up against an existing requirement, refines that requirement, supersedes the captured duplicate and rebinds the session. Validate both histories and ownership before writes. Preserve interrupted work, original prompts and truthful configured verification. Tests cover requirements, dependencies, scope, informational requests, future backlog and fallback plans. No implicit semantic model.

## Portable repository integration (L02)

Generate discoverable repository skills and a dependency-free Node intent helper under versioned ownership metadata. Never replace foreign or edited files. A fresh clone can list/read intent, save a plan, create a future idea and checkpoint without global DIP. Portable operations write causal protocol events, diagnose conflicts/corruption and cannot claim leases or produce verified code evidence. Provide upgrade, removal and opt-out paths; repository code runs only when explicitly invoked after review.

## Scale and capture costs (L08)

Before measurements: use synthetic ledgers of 100, 1,000 and 10,000 tasks, with 20 warm samples, five fresh-process samples, 20 capture records and separate setup timing. Report p50/p95, bytes, event volume and process memory. Investigation budgets on this machine: compact context p95 2 seconds at 1,000 tasks and 10 seconds at 10,000; immediate recording p95 500 ms; batched enqueue p95 100 ms; memory 512 MiB. These are investigation budgets, not platform guarantees. Measure a baseline before optimizing and preserve raw samples. Optimize measured redundant work, then repeat the same workload. A budget miss must be reported and addressed, without discarding data or changing durable semantics.

## Additional discovery adapter (L06)

Use the trusted coding-host startup/prompt hook as an explicit worktree adapter independent of Git Trace2. Prove adoption with real hook-command execution in an unmonitored worktree with native tracing disabled, including nested paths, worktrees and unsupported/bare paths. Report capabilities and disabled/missing-context cases through a read-only probe. Preserve Git configuration, stdout, exit status and unrelated hooks.

## Release validation

Run focused tests while implementing, then configured unit/browser checks, clean package smoke and cross-platform CI. Link evidence to the four existing tasks, retain any unmet criteria as open, publish only reviewed intent and source, and upgrade the local installation.
